# 劇本：開新的課程單元

老師會說：「下一個單元要開始了」「開一個新的課程單元」「幫我建○○單元的資料夾」。

腳本：`scripts/new_block.py`。

會建：

```
data/units/<單元>/
  大綱.md          單元大綱（目標、每週安排、準備、參考資料）
  session.yaml     基本資料（名稱、學年、起訖日、預計堂數）
  lessons/         逐堂教案（01-主題.md、02-主題.md…）
  texts/           學生文本（詩、故事、閱讀單）
data/courses/<單元>/records.md   課程紀錄（每上完一堂記一段）
```

已經有的檔**一律不覆蓋**。這些都在 `data/`，不上網站；`backup.py records` 會備份到雲端硬碟的「紀錄備份」。
學年照 `config/class.json` 的 `school_year.start_month` 算（依學校）。

## 1. 代理要問什麼（一次一題）

1. 「這個單元要叫什麼？」——這個名字也是課堂檔案歸檔的資料夾名，建議短、好認，直接用單元主題就好
   （例如「範例單元」「單元一」）。
2. 「哪一天開始、哪一天結束？」（不確定可以先不填）

## 2. 老師去哪裡拿

- 不用拿任何東西。單元名稱、日期老師自己知道。

## 3. 代理要做什麼

1. 說一句「我要在 data/units/ 開一個『範例單元』的資料夾，裡面放大綱、教案、學生文本的範本」，然後跑：
   `python3 scripts/new_block.py 範例單元 --start 2031-03-03 --end 2031-03-28`
   （顯示名稱跟資料夾名不一樣時加 `--title "範例單元（示範）"`）
2. 告訴老師：大綱寫在 `大綱.md`、每一堂的教案放 `lessons/`、課後紀錄寫在 `data/courses/範例單元/records.md`。
3. 之後老師口述大綱、教案時，你照範本的標題整理進對應的檔。**課程紀錄只寫「課」**；要提到某個孩子只寫座號、不寫名字，
   個別孩子的觀察請老師寫在他自己的紀錄工具（例如 teacher-records-kit）。

## 4. 怎麼驗證＋失敗怎麼辦

- 成功會列出新建的檔（「＋」），已經有的會標「沒動」。
- 「名稱不合法」：不能有 `/ \ : * ? " < > |`、不能用點或底線開頭、不能是 Windows 保留的名字（CON、NUL…）。換一個。
- 「名稱或標題裡有學生的名字」：換一個（名字會變成資料夾名與檔名，跟著檔案到處跑）。
- 開錯名字：還沒放東西的話，請老師自己把那兩個資料夾刪掉，再用對的名字開一次。
