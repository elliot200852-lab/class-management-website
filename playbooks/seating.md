# 劇本：座位表

老師會說：「排座位」「把新的座位放上去」「上傳座位表」「座位表改一下」「那個舊的座位表拿掉」。

腳本：`scripts/publish_seating.py`。一個方案一個檔：`data/seating/<起用日期>.json`（同一天第二個方案 `<日期>-2.json`）。
寫法說明：`data/seating/README.md`。放上網站後在「導師專用 → 座位表」分頁，**只有導師看得到**。
**兩段式**：預覽 → 老師說好才 `--publish`。

## 1. 代理要問什麼（一次一題）

1. 「這個座位從哪一天開始用？要叫什麼名字？」（例如「十月的座位」，從 10 月 1 日起）
2. 「從最靠黑板那一排開始，每一排由左到右（學生面向黑板時的左右）是哪幾號？中間有走道的地方也跟我說。」
   請他**只講座號**。他講了名字，你只記座號（你不知道誰是幾號，也不要去查名冊）。
3. 「有沒有空著的位子？」空位寫 `""`，走道寫 `"-"`。
4. 「要不要寫一句備註（只有你看得到）？」沒有就不寫。

排座位本身（誰坐誰旁邊）是老師的決定，**不要替他排**；他要你幫忙排，只能照他講的條件排座號，排完念給他確認。

## 2. 老師去哪裡拿

- 座號：他自己的名冊（紙本、Excel 都可以）。講座號就好，例如「第一排：1、2、走道、3、4」。
- 想先看樣子：網站上「導師專用 → 座位表」可以切換「老師站在講台看」與「學生面向黑板看」。

## 3. 代理要做什麼

1. 寫 `data/seating/<日期>.json`（UTF-8；座號一律兩位數字的文字 `"01"`，格式照 `data/seating/README.md`）。
   **不准把名字寫進檔案**（腳本會擋，而且雲端只存座號，名字由網站用名冊的稱呼補上）。
2. 預覽（唯讀，直接跑）：`python3 scripts/publish_seating.py <日期> --open`。畫面上會印出只有座號的格子圖，
   預覽檔有名字（名冊的稱呼）：請他看預覽檔確認，特別是左右方向。
   「名冊上這幾號沒有排進這個方案」是提醒（請假、轉出的可以不管），不是錯誤。
3. 他說好：「我接下來把這個座位表放上網站，只有你看得到」，他點頭才跑 `python3 scripts/publish_seating.py <日期> --publish`。
   網站上已經有同一個方案、內容又改過：腳本會擋下來，問他要不要改，點頭才加 `--update`。
4. 拿掉一個方案（本機的 json 不動）：`python3 scripts/publish_seating.py --remove <日期>`（只看網站上有沒有），
   他點頭才 `--remove <日期> --publish`。

## 4. 怎麼驗證＋失敗怎麼辦

- 成功：「✓ 已上線……讀回比對一致」。請他打開「導師專用 → 座位表」：預設顯示起用日期在今天以前、最新的那一個方案；
  點上面的按鈕可以換方案、換方向，點一個座位可以標記起來，「列印座位表」是 A4 橫式。
- 格子上顯示「座號 07」而不是名字 → 名冊還沒同步進網站（或那一號的稱呼是空的）：照 `playbooks/sync-access.md` 同步名單。
- exit 2：
  - 「座號要寫成兩位數字」「只能是座號、空位或走道」→ 你寫錯了，改檔案再預覽（不要把腳本印的內容以外的字念給他）。
  - 「座號 26 不在名冊裡」→ 打錯，或那位同學已經轉出：問他。
  - 「檔名要是方案代號」→ 檔名改成 `YYYY-MM-DD.json`。
  - 「不是合法的 JSON」→ 你寫壞了（多半是少逗號或引號），整份重寫。
  - 「已經在網站上、內容不一樣」→ 問他要不要 `--update`。
- exit 1：照「→」處理後重跑同一個指令（一樣的會略過）。
