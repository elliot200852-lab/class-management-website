# 劇本：匯出 PDF（班級紀事、學生部落格）

老師會說：「把這學期的班級紀事匯出成 PDF」「幫 3 號的部落格印一份」「全班的部落格做成一份 PDF」「期末要給家長一份」。

這個功能**在網站上做**，不用跑腳本：導師浮鈕 →「匯出 PDF」（`blog-print.html`：班級紀事；`my-child-print.html`：學生部落格），
**只有導師**打得開。用的是瀏覽器自己的「列印 → 另存為 PDF」，紙張 A4，照片用網站上的顯示圖（不是原圖）。

## 1. 代理要問什麼（一次一題）

1. 「要匯出班級紀事，還是學生的部落格？」
2. 「哪一段日期？」（例如這學期：2 月 15 日到 6 月 30 日。）不設就是全部。
3. 班級紀事：「全部分類，還是只要某一類？」／部落格：「一位學生一份，還是全班做成一份？」
4. 「要不要附上照片？」（預設附上；照片多的話 PDF 會比較大。）

## 2. 老師去哪裡拿

- 用**電腦**的 Chrome 或 Edge（手機也能存 PDF，但版面比較難調）。用導師帳號登入網站。
- 右下角的「導師」按鈕 →「匯出 PDF」；上面兩個分頁切換「班級紀事」「學生部落格」。

## 3. 代理要做什麼（陪他一步一步按）

1. 在頁面上選好日期（從、到）、分類或匯出方式。下面的清單列出範圍內的每一篇，**預設全部打勾**（已下架的預設不勾）；
   不想放的那幾篇把勾拿掉，「全選／全不選」可以一次切換。
2. 按「產生列印版」。下面會組出整份列印版（封面、目錄、每篇內文與照片），狀態列會顯示「正在準備照片：3／12 張」。
   **等到「準備好了」、「列印／存成 PDF」按鈕亮起來再按**（照片沒載完就印，那幾張會是空白）。
3. 按「列印／存成 PDF」→ 列印視窗：
   - 「目的地」選「另存為 PDF」（Mac 的 Safari：左下角「PDF」→「儲存為 PDF」）。
   - 紙張 A4；「邊界」選預設；**「頁首及頁尾」不要勾**（網站已經自己印頁碼了）；「背景圖形」可以不勾。
   - 按「儲存」，檔名預設是頁面標題（例如「班級紀事 2026-02-15 ～ 2026-06-30」），可以改。
4. 部落格「一位學生一份」：選好一位 → 產生 → 存 PDF，再換下一位。「全班一份」：每位學生會從新的一頁開始。
5. PDF 裡有孩子的照片與家長寫的文字：存在他自己的電腦或學校規定的地方；**要傳給家長前先問他**，
   而且每位家長只給他自己孩子那一份（「全班一份」只給老師自己留存）。

## 4. 怎麼驗證＋失敗怎麼辦

- 驗證：打開存好的 PDF，封面、目錄、每篇的標題與日期都在；照片方向正確；最後一頁有頁碼（舊版瀏覽器可能沒有頁碼，不影響內容）。
- 「這一頁只有導師能用」→ 登入的不是導師帳號：登出，改用導師帳號登入。
- 一直停在「正在準備照片」→ 網路不穩或今天的免費讀取額度用完了：等一下重新整理再按一次；額度的事見 `AGENTS.md`「免費方案的額度與升級」。
- 有幾張印成灰框「這張照片讀不到」→ 那張照片在網站上已經不見了（例如重發時換掉了）：可以不管，或回去重發那一篇。
- 版面被切掉、字太小 → 列印視窗的「縮放」選「預設」、紙張選 A4；還是不對就換 Chrome 再試一次。
