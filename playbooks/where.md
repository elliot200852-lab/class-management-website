# 劇本：我的資料在哪

老師會說：「我的資料在哪」「備份放在哪裡」「課程照片在哪」「打開部落格的備份」「網站網址是什麼」。

腳本：`scripts/where.py`（唯讀、不連網）。

## 1. 代理要問什麼（一次一題）

1. 「你想找的是哪一樣？」（網站、雲端硬碟上的某個夾、這台電腦上的某個夾、最新的備份）——老師已經講清楚就不用問。

## 2. 老師去哪裡拿

- 不用拿任何東西。

## 3. 代理要做什麼

1. `python3 scripts/where.py`：印出網站網址、Firebase 主控台（資料、登入過的帳號、用量）、雲端硬碟每一個夾、
   這台電腦 `data/` 每一個夾、最新的備份在哪。
2. 只挑老師問的那一兩行，用白話告訴他（不要整份念給他聽）。
3. 老師要打開：`python3 scripts/where.py --open <名稱>`（名稱是每一行括號裡的英文；`--list-names` 列出全部）。常用的：

   | 老師說 | 名稱 |
   |---|---|
   | 網站 | `site` |
   | 上課的照片與檔案（課堂檔案） | `media` |
   | 紀錄備份 | `records_backup` |
   | 部落格備份 | `blog_archive` |
   | 相簿原圖 | `album_originals` |
   | 要歸檔的收件匣 | `inbox` |
   | 課程單元資料 | `units` |
   | 網站的資料庫（主控台） | `console-data` |
   | 登入過的帳號（主控台） | `console-users` |

   不在表裡的資料夾或要給老師看的檔：直接給這個資料夾裡的路徑，例如 `--open data/personal-photos`、
   `--open exports/preview/post-<檔名>.html`（Mac、Windows 的三種終端機都是這個寫法，斜線照寫 `/`；只開資料夾與網頁、
   文字、表格、PDF、照片，不開程式）。打開的是老師螢幕上的視窗，你看不到內容。

## 4. 怎麼驗證＋失敗怎麼辦

- 每一行前面 ✓＝在，✗ 不在＝那個夾還沒建或被搬走。
- 雲端硬碟那一段顯示「！」：照 `playbooks/backup.md` 第 4 段處理（多半是雲端硬碟程式沒開）。
- 「這個位置還不存在」：還沒有東西放進去過（例如還沒歸檔過任何課程照片），正常。
