# 劇本：家長通知信（把一則觀察寫成給家長的信，老師自己按傳送）

老師會說：「寄給 3 號的家長」「幫我寫一封信給 5 號媽媽，說他最近……」。

**只在老師明講要寄給哪一位（或哪幾位）家長時才做**。不要主動提議、不要在別的工作裡順口問「要不要也寄家長」。

腳本：`scripts/parent_note.py`。**它不寄信**：只是把收件人、主旨、內文填進這台電腦的預設郵件程式（Mail、Outlook……），
由老師自己看過、自己按「傳送」。沒有接任何寄信服務，也不需要任何密碼。

家長信箱在 `data/contacts.csv`、孩子的稱呼在 `data/roster.csv`——**這兩個檔你不打開**（`AGENTS.md` 鐵則 5）。所以：
草稿裡孩子的稱呼一律寫成 **`〔孩子〕`**，腳本在打開郵件程式的那一刻才換成真的稱呼、填上家長信箱；你從頭到尾看不到名字與信箱。

## 1. 代理要問什麼（一次一題）

1. 「要寄給幾號的家長？爸爸、媽媽都寄，還是只寄其中一位？」（只講座號與稱謂，不用講名字）
2. 「要分享的是哪一段觀察？」請他貼給你或口述；用 teacher-records-kit 的，請他把那一則的文字複製給你。
3. （寫完草稿後）「這樣可以嗎？要改哪裡？」

## 2. 老師去哪裡拿

- 觀察的內容：他自己的紀錄。
- 家長信箱：不用給你，腳本從 `data/contacts.csv` 讀（暫停的、同仁都不會寄）。

## 3. 代理要做什麼

1. 把觀察改寫成給家長的信（這是協作改寫，不是逐字照抄；老師說「逐字」「定稿」就一個字都不改）。
   下面的開頭、稱呼、主旨、署名都只是**範本**：老師有自己習慣的說法（例如固定的問候語、署名方式），就照他的改，
   第一次寫之前可以先問一句「你平常寫給家長的信，開頭和署名怎麼寫？」
   - 開頭：問候＋稱呼，例如「〔孩子〕的家長您好：」，接著直接說想分享的事，不用自我介紹。
   - 語氣自然、口語；用老師真的看到的具體片段（孩子說的話、畫面、動作），少用評斷詞，**不下診斷、不貼標籤**。
   - 需要家長一起留意的地方照實寫，不要為了好聽而淡化；同時寫老師在學校打算怎麼陪孩子，
     最後給家長一件在家可以做的小事，或請他回信聊聊。
   - 健康、醫療：**不寫病名、不寫診斷**，只寫老師在學校看到、與學習和生活有關的處境，加上老師真誠的關懷。
   - 別的孩子的名字不寫進去。
   - 署名：預設 `〈班名〉 〈稱呼〉`（`config/class.json` 的 `class_name`、`teacher.display_name`）；不寫校名。
   - 主旨：簡短、具體，例如「〔孩子〕最近在學校的情形」。
2. 寫成草稿檔 `data/parent-notes/<座號>-<今天日期>.md`（UTF-8）：
   ```
   ---
   subject: 〔孩子〕最近在學校的情形
   ---
   〔孩子〕的家長您好：

   這陣子在學校看到〔孩子〕……
   ```
   老師給你的觀察裡如果有孩子的名字，寫進草稿時一律換成 `〔孩子〕`。
3. 在對話裡把**主旨與整封內文**給老師看，照他的意見改到他說好。
4. 預覽（唯讀）：`python3 scripts/parent_note.py --seat <座號> --draft data/parent-notes/<檔名>.md`
   （只寄其中一位就加 `--to 母` 之類；Windows `py -3 …`）。跟老師確認收件人數與稱謂（信箱是遮住的）。
5. 他說好 → `… --open`：郵件程式會開一封填好的信。跟他說：「請你看一下收件人、主旨、內文，沒問題就自己按傳送。」
   **你不按傳送，也不用任何方法代他寄出。**
6. 內文太長時，腳本會另外打開一份純文字檔：請他把內容全部複製貼進信裡，寄出後那份文字檔可以刪掉
   （`data/exports/` 不會上網站，但裡面有孩子的稱呼）。

## 4. 怎麼驗證＋失敗怎麼辦

- 預覽印出「收件 N 位」、稱謂對；「〔孩子〕出現 N 次」至少 1 次（稱謂那一行）。
- 「座號 N 找不到可以寄的家長」→ 那個座號在 `contacts.csv` 沒有信箱、或都是暫停：請老師自己打開 `contacts.csv` 看。
- 「data/roster.csv 裡沒有座號 N」→ 座號講錯了，或名冊還沒填。
- 按了 `--open` 沒有反應：這台電腦沒有設定預設郵件程式（例如只用 Gmail 網頁版）。Mac：打開「郵件」→ 設定 → 一般 →
  預設郵件程式；Windows：設定 → 應用程式 → 預設應用程式 → 電子郵件。或請他在 Gmail 網頁版自己新增一封，你把內文
  （用 `〔孩子〕` 的版本）給他，他自己換成孩子的名字。
- 老師想改寄件的信箱：那是郵件程式裡的帳號設定，在郵件程式裡選就好。
