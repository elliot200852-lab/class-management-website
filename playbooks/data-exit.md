# 劇本：資料退場（學生轉出、家長要求刪除自己的資料）

老師會說：「3 號轉走了，資料要清掉」「某某家長要我們刪掉他的資料」「這位家長不要再用網站了，把他寫的東西刪掉」。
學年結束走另一份：`playbooks/year-end.md`。

腳本：`scripts/data_exit.py`。**刪了就回不來**，所以：預設只預覽；加 `--apply` 才做，做之前**自動先備份整個網站資料庫**
（備份失敗就停，一筆都不刪）。

## 1. 代理要問什麼（一次一題）

學生轉出：

1. 「是幾號？」
2. 「那些家長寫過的留言要怎麼處理：**收起來、署名改成『已退場家長』**（預設，留言串上下文還在），還是**整則刪掉**？」
3. 「舊的備份裡也有這位孩子的資料，要**現在就清掉**，還是讓它照 30 份輪替慢慢淘汰？」

家長要求刪除：

1. 「是哪一位家長？請給我他登入網站用的信箱。」（信箱只用在這一次指令，輸出只會出現遮住的 `p***@…`）
2. 同上第 3 題（舊備份）。

## 2. 老師去哪裡拿

- **順序很重要：先讓你跑一次預覽（第 3 段第 1 點），再請老師改名單檔。** 預覽會把「要刪的登入帳號」的完整信箱
  從 `contacts.csv` 抄進一份只給老師開的清單（`data/exports/data-exit/<座號或代號>-auth-cleanup.txt`）；
  那幾列一刪，程式就再也查不到完整信箱，老師到時候在主控台會找不到要刪哪個帳號。
- **然後改好這台電腦的名單檔**（腳本會檢查，沒改好就停，免得下次名單同步又把人加回去）：
  - 學生轉出：請老師用 Excel／Numbers 打開 `data/roster.csv`、`data/contacts.csv`，刪掉那個座號的每一列（家長、同仁都算）。
    `data/parent-roles.yaml` 裡那個座號那一行，你可以幫他刪（這個檔沒有姓名與信箱）。
  - 家長刪除：請老師打開 `data/contacts.csv` 刪掉那位家長那一列；如果那個座號從此沒有這個稱謂的家長，
    `parent-roles.yaml` 裡那個稱謂也拿掉。
- **你不要自己打開 roster.csv、contacts.csv**（有真名與信箱；你的設定也擋住了）。

## 3. 代理要做什麼

1. **在老師改名單檔之前**先預覽一次（唯讀，直接跑）：
   - 學生轉出：`python3 scripts/data_exit.py seat 03`
   - 家長刪除：`python3 scripts/data_exit.py parent --email <信箱>`
2. 預覽會列出：要撤掉誰的權限、要改哪些、要刪哪些（網站資料庫）、這台電腦與雲端硬碟要刪哪些資料夾，
   完整清單寫在 `data/exports/data-exit-….txt`。**把重點講給老師聽**，特別是「會刪 N 篇部落格文章、N 張照片」。
   有家長要刪登入帳號時，它還會印「要刪的登入帳號（完整信箱）：data/exports/data-exit/…-auth-cleanup.txt」：
   那份**只給老師自己打開**（有完整信箱；你的設定擋住了 `data/exports/`，你不讀、不念、不抄）。
   它說「有 N 位的完整信箱這台電腦已經找不到了」＝名單檔已經先刪了：清單上只剩遮住的開頭與網域，請老師在主控台對照著找。
3. 預覽說「還不能做：名單檔要先改好」→ 這時才回到第 2 段請老師改名單檔，改好再預覽一次（清單檔會保留剛剛抄下的信箱）。
4. 老師明確說「好，刪」之後才跑（照第 1 段他的回答決定要不要加後面兩個旗標）：
   - `python3 scripts/data_exit.py seat 03 --apply`（留言整則刪：加 `--delete-comments`；現在就清舊備份：加 `--purge-backups`）
   - `python3 scripts/data_exit.py parent --email <信箱> --apply`（現在就清舊備份：加 `--purge-backups`）
5. 做完後，把腳本最後印的「老師要自己做的事」念給老師聽，陪他做完：
   - **刪登入帳號**：先幫他打開那份清單（`python3 scripts/where.py --open data/exports/data-exit/<檔名>-auth-cleanup.txt`，
     檔名照預覽印的；打開的是他螢幕上的文字編輯器，你看不到內容），再打開主控台
     （`python3 scripts/where.py --open console-users`）→ Authentication → 使用者 → 搜尋框貼清單上的信箱 →
     那一列右邊「⋮」→ 刪除帳戶。全部刪完，那份清單請他自己丟垃圾桶。
   - 學生轉出：請老師在網站上看過班級紀事、相簿、私密紀事裡**有沒有這位孩子的照片或文字**（程式找不出來）；
     要換照片就改母本重發（`playbooks/class-post.md`、`album.md`），要下架就 `visible: false`。
6. 學生轉出時，同步夾 `01_機密（只有導師）/學生個別資料/<座號>/` 與 `04_部落格歸檔/<座號>/` 也會刪（雲端硬碟的垃圾桶會留 30 天）。

## 4. 怎麼驗證＋失敗怎麼辦

- 成功：「✓ 完成：撤權限 N 份、改 N 份、刪 N 份…」。再跑一次同一個預覽，應該幾乎沒有要刪的了。
- 請老師用那位家長的帳號（或請家長）試著登入：應該進不去網站。
- exit 2「備份沒有成功，所以一筆都沒刪」：先照 `playbooks/backup.md` 把備份修好。
- exit 1（網路、額度）：做到一半停下來沒關係，修好後再跑同一個 `--apply`，會從目前的狀態接著做。
  免費方案每天最多刪 20,000 份，超過就明天再跑。
- 「查不到這位家長的作者代號」：他可能很久以前就被移出名單了，程式找不到他寫過的留言。請老師在網站的留言後台看過，
  需要的話手動收起。
- exit 1「這台電腦或雲端硬碟同步夾有 N 個項目刪不掉」：網站資料庫已經刪好了，只是有檔案被別的程式開著
  （Windows 上雲端硬碟程式常鎖著照片）。請老師關掉開著的檔、等雲端硬碟同步完（或暫停同步），再跑同一個 `--apply`；
  還是不行，請他照印出來的路徑自己在 Finder／檔案總管刪。**沒刪乾淨之前不要跟老師說「刪好了」。**
- 不小心刪錯：做之前的那一份備份還在（`python3 scripts/backup.py list` 看代號），照 `playbooks/restore.md` 用 `--only` 救回來。
  退場時記了一筆退場台帳（`data/ledgers/data-exit.jsonl`，只有座號與雜湊），所以還原會停下來說「已經退場的資料」：
  確認是退場做錯了、老師明講要救回來，才加 `--include-exited`；名單另外照 `playbooks/sync-access.md` 加回去。
  （加了 `--purge-backups` 的話舊備份已經清掉，救不回來——所以第 1 段一定要問。）

## 5. 孤兒照片（`status.py` 或 `backup.py firestore` 說「孤兒照片 N 份」）

學生部落格底下有照片文件沒掛在任何文章上（文章不存在，或文章的照片清單沒列到）。網頁上看不到，只佔免費方案的 1 GiB。
正常用網頁發文不會產生（文章和照片是同一批，一次成功或一次失敗），所以出現了多半是**有人拿某位家長的帳號繞過網頁直接寫**。
安全規則為了讀取次數預算，沒辦法在寫照片時檢查文章在不在（`docs/DATA-MODEL.md` §1.6），而且沒有數量上限：
**單一家長帳號就能灌滿整個資料庫的容量**，滿了之後全班的發文、留言、回條都會失敗。處置：

1. 看是哪個座號、多少份、多大（`status.py` 或備份的輸出；只有座號、數量、大小、遮住的文章代號，沒有內容）。
   份數很少、大小很小，而且老師想得到原因（例如某次發文網路斷掉），先記下來，下次備份再看有沒有變多。
2. 份數多、或一直變多：跟老師講清楚「這個座號的家長帳號可能被別人拿去用了，或有人在亂寫」，請他聯絡那個座號的家長確認。
3. 要停止：先撤掉那個帳號——老師把那位家長從 `contacts.csv` 刪掉，照 `playbooks/sync-access.md` 同步（撤權限之後就寫不進來了）；
   家長的登入帳號在主控台 Authentication 停用或刪除（帳號被盜時請家長改 Google 密碼）。
4. 清掉孤兒照片：`python3 scripts/data_exit.py parent --email <那位家長的信箱>`（照第 3 段的預覽→`--apply` 流程）；
   預覽會多一行「座號 N 底下的孤兒照片 M 份一起刪」。家長還要留在網站上（只是清孤兒）：這一版沒有單獨清孤兒的指令，
   跟老師說明、先記下來，容量真的吃緊再決定要不要走家長退場。學生轉出（`seat`）會連那個座號的孤兒照片一起刪。
5. 容量已經滿了、網站寫不進去：先做第 3 點擋住來源，再做第 4 點；還是不夠就照 `AGENTS.md`「免費方案的額度與升級」一節。
