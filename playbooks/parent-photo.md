# 劇本：家長合照（只有導師看得到）

老師會說：「4 號的家長合照」「把這張家長照片放上去」「用 3 號部落格那張當家長合照」「4 號家長合照撤掉」。

腳本：`scripts/publish_parent_photo.py`。在「個人照」相簿點開一位孩子時，跟孩子的照片**並排**的那一張，**只有導師看得到**。
雲端只存照片與**稱謂**（母、父、祖母……），**不存家長姓名**；稱謂預設取 `data/parent-roles.yaml` 裡那個座號寫的。
寫法說明：`data/parent-photos/README.md`。**兩段式**：預覽 → 老師說好才 `--publish`。

## 1. 代理要問什麼（一次一題）

1. 「是幾號的家長？」
2. 「照片從哪裡來？一張你電腦裡的照片，還是那位孩子部落格裡某一篇文章的照片？」
3. 「照片裡是哪幾位？」我會先念 `parent-roles.yaml` 裡那一號寫的稱謂（例如「母、父」）；照片裡只有其中幾位，就只標那幾位。
4. 「要不要寫一句備註？」（只有你看得到，最多 200 字；例如在哪裡拍的。）沒有就不寫。

家長的照片你**不打開、不看**。對不對由老師看預覽檔確認。

## 2. 老師去哪裡拿

- 本機照片：建議改名成座號放進 `data/parent-photos/`（例如 `04.jpg`；你幫他打開那個資料夾）。原始檔名不會上網。
- 部落格文章的照片：請他在網站上打開那篇文章，網址最後一段就是文章編號（像 `2026-10-03-ab12cd34`）；
  那篇的第幾張照片（第 1 張＝`--photo 0`、第 2 張＝`--photo 1`、第 3 張＝`--photo 2`）。

## 3. 代理要做什麼

1. 預覽（唯讀，直接跑）：
   - 本機照片：`python3 scripts/publish_parent_photo.py --seat 4 --from-file data/parent-photos/04.jpg --open`
   - 部落格照片：`python3 scripts/publish_parent_photo.py --seat 4 --from-blog 2026-10-03-ab12cd34 --photo 1 --open`
     （這一種預覽會連上網站讀那張照片，只讀不寫；登入過期就請他打 `gcloud auth login`）
   - 只標其中幾位：加 `--who 母`（多位用逗號：`--who 母,祖母`，只能挑 `parent-roles.yaml` 裡那一號寫過的稱謂）。
   - 備註：加 `--note "運動會那天"`。
2. 請他看預覽檔（照片、稱謂）。他說好：「我接下來把這張家長合照放上網站，只有你看得到」，他點頭才在同一行最後加 `--publish`
   （腳本預覽完會印出完整的那一行）。
3. 那一號已經有家長合照、要換一張或改稱謂：腳本會擋下來，他同意後加 `--update`（舊照片會從網站刪掉）。
4. 撤掉：`python3 scripts/publish_parent_photo.py --remove 4`（只看網站上有沒有），他點頭才加 `--publish`。

## 4. 怎麼驗證＋失敗怎麼辦

- 成功：「✓ 已上線 1 張……讀回比對一致」。請他打開「個人照」，點那一位孩子：右邊是家長合照，下面寫「家長合照：母、父」。
- exit 2：
  - 「不知道照片裡是誰」「座號 N 沒有宣告任何家長稱謂」→ 問他照片裡是誰，用 `--who`。
  - 「--who 寫的稱謂不在 parent-roles.yaml」→ 用那一號寫過的稱謂；真的有新的家長稱謂，照 `playbooks/sync-access.md` 先改名單。
  - 「那篇文章沒有第 N 張照片」「找不到文章」→ 文章編號或座號、`--photo` 數字弄錯了：請他再看一次網址。
  - 「座號 N 不在名冊裡」、「需要 Pillow」、「已經在網站上、內容不一樣」→ 同 `playbooks/personal-photos.md`。
- exit 1：照「→」處理後重跑同一行。
