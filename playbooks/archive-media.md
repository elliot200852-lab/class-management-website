# 劇本：課程歸檔（上課的照片、影片、音檔、文件 → 雲端硬碟的課堂檔案）

老師會說：「課程歸檔」「把今天的板書照片收起來」「這些是○○單元的作業本」「inbox 裡的東西幫我整理」。

腳本：`scripts/archive_media.py`。

這是**只有導師自己看得到**的教學檔案：放進雲端硬碟 `01_機密（只有導師）/課堂檔案/<學年>/<單元>/`，**不分享給任何人**。
要給家長看的照片走相簿（`playbooks/album.md`），不是這份——走錯一條就是把學生照片給出去，**分不清楚就先問老師**。

檔名一律：`YYYYMMDD-單元-類型-說明.副檔名`，例如 `20310303-範例單元-板書-單元重點.jpg`。
學年資料夾照 `config/class.json` 的 `school_year.start_month` 算（依學校）。
**類型只准五個**：板書｜作業本｜課堂活動｜教材｜其他。

## 1. 代理要問什麼（一次一題）

1. 「這些是哪一個單元的？」（`data/units/` 裡已經有的名字；沒有的話問「要不要開一個新的單元叫 ○○？」→ `playbooks/new-block.md`）
2. 「是哪一天上的課？」——只有照片沒有拍攝日期、而且老師沒說的時候才問（程式會先用照片的拍攝日期）。
3. 看不出內容的檔：「這張是什麼？」——**只問內容，不寫名字**。

## 2. 老師去哪裡拿

- 把照片、影片、音檔、文件丟進這個資料夾的 `data/inbox/`（`python3 scripts/where.py --open inbox` 可以直接打開它）。
  手機上的照片：用 AirDrop、LINE 傳到電腦、或 Google 相簿下載，存進 `data/inbox/`。

## 3. 代理要做什麼

1. `python3 scripts/archive_media.py`（唯讀）列出 inbox 的檔、推得出的日期、是不是已經歸檔過。
2. **每一張照片、每一份文件都要真的打開來看**（影片看開頭一格），依內容決定類型與說明：
   - 說明寫「內容」、**不寫人**：作業本封面常有姓名欄，一律寫成「作業本-主題」（例如「作業本-練習一」）。
   - 看不清楚的專有名詞，寧可寫泛稱（「黑板上的示意圖」），不要猜——錯的名字會跟著檔名留十年。
   - 說明最多 40 字，不能有 `/ \ : * ? " < > |`。
3. 組一份清單（JSON），存在 `data/inbox/` 以外的地方（例如 `data/exports/歸檔清單.json`）：
   ```json
   [{"file": "IMG_0012.jpg", "type": "板書", "desc": "單元重點", "date": "20310303"},
    {"file": "講義.pdf", "type": "教材", "desc": "單元講義"}]
   ```
   只有一個檔也可以不用清單：`--file IMG_0012.jpg --type 板書 --desc 單元重點`。
4. 預覽（不動任何東西）：`python3 scripts/archive_media.py --block 範例單元 --manifest data/exports/歸檔清單.json`
5. 把預覽的檔名念給老師聽，說「我要把這幾個檔放進你雲端硬碟的課堂檔案，放好後 inbox 的原檔會移到垃圾桶」，點頭後加 `--apply`。
6. **影片一次只處理一支**（清單裡有兩支影片會被擋）：一支一支跑。

## 4. 怎麼驗證＋失敗怎麼辦

- 每個檔都「✓ …（md5 已比對）」：放進雲端硬碟的那一份讀回來跟原檔一模一樣，才把原檔移到垃圾桶。先驗後刪，永不顛倒。
- 「說明裡有學生的名字（座號 03）」：改說明，寫內容不寫人。**不要**為了過關改名冊。
- 「還沒有『○○』這個課程單元」：打錯字就改；真的是新的，先問老師再走 `playbooks/new-block.md`。
- 「已經歸檔過」：同一個檔（內容一模一樣）已經在雲端硬碟了，不會重複放。
- 「老師之前在雲端硬碟刪掉了這個檔，不重傳」：老師刪過的檔，程式記得，不會自己放回去。老師明講要重新歸檔，
  請他先到雲端硬碟的垃圾桶把原本那個救回來（下次歸檔會自動對帳）。
- 「沒辦法放進系統垃圾桶，已搬到 data/inbox/.archived/」：確認雲端硬碟上有了，請老師自己把那個資料夾清掉。
- 「課程夾整個不見了／全部不見了，先不對帳」：多半是雲端硬碟還沒同步下來，不用處理；持續出現就請老師看雲端硬碟程式有沒有開。
- 雲端硬碟上傳：請老師看雲端硬碟圖示「已是最新狀態」。
