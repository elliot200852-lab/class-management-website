# 劇本：科任大綱入檔（一份大綱放三個地方）

老師會說：「科任大綱入檔」「英文老師寄大綱來了，幫我放上去」「課程頁補一格美術課」。

科任老師把教學大綱寄給導師，這份東西有三個去處，缺一個就是半套：

| # | 放哪裡 | 形式 | 給誰看 |
|---|---|---|---|
| 1 | 這台電腦 `data/courses/syllabi/<學年>-<科目>.md` | 文字（逐字） | 導師自己、之後備課時代理查得到 |
| 2 | 雲端硬碟 `02_分享給家長/科任課程大綱/` | 原件 PDF（**乾淨版**） | 家長點連結看原件 |
| 3 | 網站「課程」頁的〈各科課程大綱〉卡 | 一張卡片 | 家長在網站上瀏覽 |

老師只說「補網站那一格」就只做第 3 項；只說「轉成文字」就只做第 1 項。
用到的腳本：`scripts/where.py --open syllabi`、`scripts/publish_courses.py`（`playbooks/courses.md`）。

## 0. 個資閘（第一步，沒做完不准往下）

科任老師的大綱原本是寫給導師的，裡面常夾著不該給家長看的東西。**把 PDF 每一頁都看過**（用你的讀檔工具看頁面；
不要只信抽出來的文字，中文 PDF 常靜默掉字），逐項確認：

| 看到什麼 | 怎麼辦 |
|---|---|
| 表單裡的個人聯絡資料、帳號資訊（例如報名或收費用的欄位） | **整段不進三處任何一處**。有這些內容的原件不上雲端硬碟：請導師跟科任老師要一份只有課程內容的版本，或導師自己在電腦上刪掉那幾頁另存 |
| 任何一位孩子的名字、座號或個別情況 | 一樣整段拿掉，三處都不放 |
| 老師的私人電話、住址、LINE ID | 拿掉（學校公務信箱可以留） |
| 寫給導師的稱呼與交代（「○老師好：……」） | 家長看的兩處拿掉；第 1 項的文字檔保留（那是出處） |
| 純課程內容：目標、進度、要準備的用品 | 可以公開 |

掃到的東西跟導師講清楚（講類別，不要念出帳號或姓名）；大綱本體就是一張掃描圖或手寫照片 → 停下來問導師，不要自己重打。

## 1. 代理要問什麼（一次一題）

1. 「這份是哪一科、哪位老師、哪一學年、涵蓋哪幾個學期？」
2. 「要放三個地方都做嗎？」（通常是）
3. 卡片要放全文還是摘要：大綱只有一兩段 → 「我把老師原文直接放在卡片上、不附 PDF 連結，可以嗎？」；
   好幾頁、有週次進度表 → 「卡片我寫兩三句說明，再附 PDF 連結，可以嗎？」

## 2. 老師去哪裡拿

- 大綱檔（信件附件）：請他存到電腦上，告訴你檔案在哪。
- 分享連結（第 2 項放好之後）：雲端硬碟網頁版 → `〈班名〉 班級網站` → `02_分享給家長` → `科任課程大綱` → 在那個 PDF 上按右鍵 →
  「共用」→「一般存取權」改成「知道連結的任何人」、角色「檢視者」→「複製連結」→ 貼給你。
  **只分享那一個檔，不要分享資料夾**（資料夾分享了，之後放進去的檔會自動跟著公開）。

## 3. 代理要做什麼

1. **第 1 項（文字檔）**：寫 `data/courses/syllabi/<學年>-<科目>.md`（UTF-8；例 `2030-2031-英文.md`）：
   ```
   ---
   subject: 英文
   teacher: 王老師
   school_year: 2030-2031
   terms: 上學期、下學期
   domain: 語文（英語）
   converted_at: 2030-09-15
   ---
   （科任老師的原文照抄：可以整理成標題、清單、表格，句子本身一個字都不動，不刪減也不加字）

   > 原件有幾段含個人資料，沒有收進來；需要時看導師信箱裡的原件。（有拿掉東西時才加這一行）
   ```
   圖片不抽出、不描述；原件裡的圖就留在原件裡。
2. **第 2 項（PDF）**：`python3 scripts/where.py --open syllabi` 打開 `02_分享給家長/科任課程大綱/`，請導師把**乾淨版** PDF 拖進去。
   檔名建議 `<學年> <科目>課程大綱（<老師>）.pdf`，一定要 `.pdf` 結尾。同名檔已經在了 → 問他「新的叫 _v2，還是換掉舊的？」
   然後照第 2 節請他分享那一個檔、把連結給你。
3. **第 3 項（網站卡片）**：在 `data/courses/<課程頁>.md`（例如 `courses-term.md`；沒有就照 `playbooks/courses.md` 建一份）的
   `## 各科課程大綱` 底下加一張：
   ```
   ### 英文（王老師）
   這學期讀三本繪本、唱英文歌，練習用簡單的句子說自己的事。
   網址：<第 2 項複製的分享連結>
   ```
   - 短大綱：老師原文逐字放進說明（≤ 300 字，標點可以統一成全形），**不加**「網址：」那一行。
   - 長大綱：你寫兩三句給家長看的導讀：這學期做什麼、練什麼；不用教育術語，費用、評分方式、節數這類細節留在 PDF 裡。
     **寫好先請導師過目**：這段話是用導師的名義對家長說的，用字照他的習慣改。
4. 預覽：`python3 scripts/publish_courses.py <課程頁> --open` → 導師說好 → `--publish`（已上線的課程頁是 `--publish --update`）。
5. 換學期：涵蓋整學年的大綱不用每學期重放，下一學期的課程頁直接用同一個連結；科任老師改版才重跑，文字檔加一行 `revised_at:`。

## 4. 怎麼驗證＋失敗怎麼辦

- 第 1 項：文字檔的內容跟原件逐段對得上（抽查表格與數字），沒有個資閘擋下的東西。
- 第 2 項：請導師用手機（**沒有登入 Google** 的瀏覽器，例如無痕視窗）點分享連結，打得開；打不開＝分享沒設好，回第 2 節。
- 第 3 項：「✓ 已上線……讀回比對一致」；網站「課程」頁看得到那張卡，點「看課程大綱」打得開 PDF。
- `publish_courses.py` 的錯誤訊息照 `playbooks/courses.md` 處理。
