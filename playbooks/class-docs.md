# 劇本：班級文件（歸檔＋索引）

老師會說：「把這份文件放進班級文件」「更新班級文件索引」「上次座談會的簡報放哪」「導師專用頁的班級文件按鈕」。

腳本：`scripts/docs_index.py`（產生索引）、`scripts/where.py --open class_docs`（打開資料夾）、
`scripts/publish_site.py --class-docs`（導師專用頁的按鈕）。

班級文件放在雲端硬碟同步夾的 `01_機密（只有導師）/班級文件/`，**只有導師自己看得到、不分享給任何人**。底下的資料夾
（`scripts/drive_init.py` 建的）：`通用文件`（每年都用得到的）、`會議紀錄`、`課程`，以及每個學年一夾
（例如 `2030-2031`），裡面每個學期一夾。學期叫什麼、學年從幾月開始，照 `config/class.json` 的 `school_year`
（依學校；預設是 `上學期`、`下學期`，分三個學期的學校可以設成 `第一學期`、`第二學期`、`第三學期`）。
老師以前自己建的資料夾用別的叫法（例如設定是 `上學期`、舊資料夾叫 `第一學期`）→ 在 `school_year.term_aliases`
登記別名，索引的「學期」欄就會認得（格式見 `config/README.md`；資料夾本身不用改名）。
老師想多分幾格（例如某個活動專用的夾），自己在雲端硬碟裡建就好，索引照樣會掃到。
要給家長看的文件不放這裡：科任大綱走 `playbooks/subject-syllabus.md`（`02_分享給家長`），其他走班級紀事或單頁。

## 1. 代理要問什麼（一次一題）

1. 「這份文件要放哪一格？」照上面的資料夾念給他選（跟某個學期有關就放學年底下那個學期；每年都用的放 `通用文件`）。
   **沒講清楚就先問，不要自己猜**。
2. 新文件的檔名：「檔名要不要改？」檔名一定要留副檔名（`.pdf`、`.docx`……），不然很多程式打不開。

## 2. 老師去哪裡拿

- 文件本身在老師手上（信件附件、下載的檔）。
- 打開那個資料夾：`python3 scripts/where.py --open class_docs`（Windows `py -3 …`），**請老師自己把檔案拖進對的那一格**。
  班級文件常有學生或家長的個資：代理不經手、也不打開文件內容。

## 3. 代理要做什麼

1. 老師放好之後，預覽索引（唯讀，只印數量、不印檔名）：`python3 scripts/docs_index.py`
2. 講一句「我要更新班級文件的索引 index.md」，他點頭 → `python3 scripts/docs_index.py --apply`。
   索引在 `班級文件/index.md`，一列一份文件：名稱｜類別｜學年｜學期｜位置。雲端硬碟會自己上傳。
3. 他想看：`python3 scripts/docs_index.py --open`（用系統預設程式打開 index.md）。
4. 「類別」欄可以改：老師說「那份簡報的類別改成座談會資料」→ 用你的寫檔工具只改 index.md 那一列的第二欄（UTF-8），
   下次重跑會保留。其他欄每次都會重新對齊資料夾，不要手改。
5. **導師專用頁的「班級文件」按鈕**（第一次設定一次就好）：
   1. 請老師用電腦瀏覽器打開 <https://drive.google.com> → `〈班名〉 班級網站` → `01_機密（只有導師）` → `班級文件` →
      點兩下 `index.md` → 右上「⋮」→「在新視窗中開啟」→ 複製網址列的網址給你。
   2. `python3 scripts/publish_site.py --class-docs "<網址>"`（預覽）→ 他點頭 → 加 `--apply`。
   3. 這個網址只有導師讀得到（網站規定），而且雲端硬碟上的檔案本身也只有他自己有權限。**不要在雲端硬碟上把這個檔或資料夾分享出去**。

## 4. 怎麼驗證＋失敗怎麼辦

- 成功：`✓ 已寫入 index.md`；再跑一次預覽是「index.md 已經是最新的」；`docs_index.py --check` exit 0。
- exit 2「找不到雲端硬碟同步夾」「資料夾樹少了班級文件」→ 雲端硬碟程式沒開，或資料夾被改名、搬走：照「→」處理，
  **不要自己另外建一個**（`playbooks/backup.md` 的同步夾那一段）。
- 某份文件沒出現在索引：檔名是點開頭、`~$` 開頭（Office 的暫存檔）或還在下載中的檔，程式會故意跳過；確認檔案真的在資料夾裡。
- 學年、學期是「—」：那份文件不在學年／學期資料夾裡（例如放在 `會議紀錄`），這是正常的。
- 學期欄是空的「—」，但檔案明明放在學期資料夾裡：那個資料夾的名字跟 `school_year.terms` 對不上（例如設定寫 `上學期`、資料夾叫 `第一學期`）。改資料夾名或改設定，兩邊一致就好。
- Google 文件、試算表在同步夾裡是 `.gdoc`、`.gsheet` 這種捷徑檔，索引照樣列（類別「文件」「表格」）。
