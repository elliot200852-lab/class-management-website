# 劇本：替學生發部落格文章（導師發文）

老師會說：「幫 3 號發一篇部落格」「把這段寫進 5 號的部落格」「改一下 3 號那篇」。家長自己發的文章在網站上直接發，不經過這裡。

腳本：`scripts/publish_blog.py`。草稿在 `data/blog-drafts/<座號>/<草稿名>.md`，照片在 `data/blog-drafts/<座號>/<草稿名>/`（最多 3 張）。
寫法說明：`data/blog-drafts/README.md`。**兩段式**：預覽 → 老師說好才 `--publish`。

## 1. 代理要問什麼（一次一題）

1. 「幾號？」——只收座號。老師說名字的話，請他告訴你座號（你不要打開名冊去對）。
2. 「標題？內容？」**正文逐字保留**：他給的文字照原樣放（空白、換行都不動），不要潤飾、不要加結尾的客套話。
3. 「有照片嗎？最多 3 張。」超過 3 張請他自己挑，不要替他選；圖說沒給就留空。

## 2. 老師去哪裡拿

- 照片：存進 `data/blog-drafts/<座號>/<草稿名>/`（你告訴他資料夾位置）。
- 那個座號的部落格要先開（`open-blogs.md`）；名單要先同步過一次（`sync-access.md`，導師的作者代號在那裡產生）。

## 3. 代理要做什麼

1. 草稿名用「日期-英文小寫」（例如 `2026-10-03-math`），建 `data/blog-drafts/<座號>/<草稿名>.md`：
   檔頭 `title`（必填）、`date`（選填）、`photos:`（「- 檔名 | 圖說」），檔頭下面是正文。
2. 預覽並打開給他看：
   ```
   python3 scripts/publish_blog.py --seat 3 <草稿名> --open
   ```
3. 他說好：「我接下來要把這篇發到 3 號的部落格，3 號的家長登入就看得到」，他點頭才跑：
   ```
   python3 scripts/publish_blog.py --seat 3 <草稿名> --publish
   ```
4. 發完要改字：改草稿，預覽，他同意後 `--publish --update`（只改標題與正文；照片發了就不能換——
   要換照片請他在網站上把那篇下架，再用**新的草稿名**發一篇）。

## 4. 怎麼驗證＋失敗怎麼辦

- 成功：「✓ 已發到座號 N 的部落格（postId …），讀回比對一致」。家長打開「我的孩子」就看得到。
- 「這份草稿已經發過了」「已經有一篇同標題、同日期的導師文」：擋下來是為了不要出現兩篇一樣的。
  要改那篇就問他要不要 `--update`；真的要再發一篇，請他改標題、用新的草稿名。
- 「部落格還沒開」→ 先走 `open-blogs.md`；「名單裡還沒有導師的作者代號」→ 先走 `sync-access.md`。
- 一篇文章是一次送出的：失敗就是整篇都沒發，修好後重跑同一個指令（會換一個新的 postId）。
