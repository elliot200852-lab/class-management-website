# 劇本：健檢

老師會說：「健檢」「檢查一下」「網站怪怪的」「家長說登入不了」「照片看不到」。

腳本：`scripts/doctor.py`（這台電腦）與 `scripts/doctor.py --cloud`（雲端設定）。**全部唯讀**，直接跑，不用先問。

## 1. 代理要問什麼（一次一題）

1. 「哪裡怪？」（誰、在什麼裝置、看到什麼畫面或訊息）——請他盡量照原樣念出畫面上的字，或截圖（截圖前先確認沒有別人的資料）。
2. 家長登入不了：「他用的是 Google 帳號，還是信箱登入連結？他在 LINE 裡直接點開的嗎？」

## 2. 老師去哪裡拿

- 家長的畫面：請家長截圖給老師。常見：「這個帳號還沒有開通」＝那個信箱不在名單裡；
  「請用手機的瀏覽器開啟」＝在 LINE 裡面開的（要點右上角改用瀏覽器開）。
- Firebase 主控台：https://console.firebase.google.com （用開專案的那個帳號登入）。

## 3. 代理要做什麼

1. 這台電腦：`python3 scripts/doctor.py`。缺什麼工具就把官方連結給老師，請他自己裝（不代裝），裝完重開終端機再跑。
2. 雲端：`python3 scripts/doctor.py --cloud`。每一項 ✓／✗／！，✗ 下面有「→」說明怎麼處理：
   - 登入帳號（gcloud、firebase 要都是導師信箱）、資料庫地區、登入網域＝網站網址、登入方式（Google、信箱連結）、
     索引都建好、線上規則＝本機這份、方案（Spark／Blaze）、網站有上線、名單包含關係。
   - 「部署前」就要過的有 ✗：照說明到 Firebase 主控台設定；「部署後要過」的有 ✗：多半是還沒部署或改了設定沒部署 → `deploy.md`。
3. 家長登入不了、看不到內容：
   - 跑 `python3 scripts/access_sync.py`（預覽）看他在不在名單、座號對不對；不在就請老師改 `contacts.csv` 再走 `sync-access.md`。
   - 「我的孩子」只接受 Google 登入：用信箱連結登入的家長看得到班網、看不到部落格。
   - 免費方案全網站每天只能寄 5 封信箱登入信：請家長改用 Google 帳號，或隔天再試。
4. 照片看不到：先確認那篇有上線、`visible` 不是 `false`；再請家長重新整理。還是不行就跑 `doctor.py --cloud` 看索引與規則。

## 4. 怎麼驗證＋失敗怎麼辦

- `doctor.py` 的 exit 0＝這台電腦的必要工具都在；exit 1＝有必要項 ✗（照它印的官方連結請老師自己裝）。選用項的 ！不算失敗。
- `doctor.py --cloud` 的 exit 0＝部署前必要項都過；「！無法判斷」不算失敗（例如讀不到帳單資訊）。
- 讀雲端時出現「gcloud 還沒登入」「權限不足」：請老師 `gcloud auth login`（用開專案的那個帳號）。
- 查不出原因：把 `doctor.py --cloud` 的輸出（裡面沒有完整信箱）與家長的截圖一起整理給老師，說明你查過哪些、還剩哪些沒辦法從這裡看到。
