# 劇本：開學生部落格（「我的孩子」）

老師會說：「開部落格」「幫全班開部落格」「幫 3 號開部落格」「3 號的稱呼改一下」「換頭像」。

腳本：`scripts/open_blogs.py`。讀 `data/roster.csv`（座號、稱呼），為每個座號開一份部落格主頁。
**預設只預覽**，`--apply` 才寫。**從不刪部落格**（轉出走資料退場）。

## 1. 代理要問什麼（一次一題）

1. 「要開全班，還是只開某幾號？」
2. 如果是新轉入的孩子：「名冊（`data/roster.csv`）加上他了嗎？稱呼要叫什麼？」——請老師自己用 Excel 加一列
   `座號,姓名,稱呼,`（稱呼只放名、不放姓，最多 10 字）。你不要打開 `roster.csv`。
3. （選用）「要放頭像嗎？」要的話請他把照片存成 `data/avatars/<座號>.jpg`（檔名只能是座號）。

## 2. 老師去哪裡拿

- 稱呼：老師自己決定（家長在「我的孩子」頁面上看到的孩子名字）。
- 頭像：任何一張照片；腳本會縮小、清掉 EXIF 與定位資訊。

## 3. 代理要做什麼

1. 預覽（唯讀）：
   ```
   python3 scripts/open_blogs.py                 （全班）
   python3 scripts/open_blogs.py --seat 3        （只看 3 號；可以給好幾個 --seat）
   ```
   把「要新開幾個、要更新哪幾號」講給他聽（輸出只有座號，不會出現孩子的名字）。
2. 他說好：「我接下來要幫這幾位開部落格，開好之後對應的家長登入就看得到」，他點頭才跑同一個指令加 `--apply`。
3. 家長要看得到自己孩子的部落格，還需要名單裡有「家長對座號」：沒同步過就接著走 `sync-access.md`。

## 4. 怎麼驗證＋失敗怎麼辦

- 成功：「✓ 已寫入 N 個座號的部落格主頁，讀回比對一致」；再跑一次預覽是「部落格都開好了」。
- 請老師用導師帳號打開網站的「我的孩子」→ 全班格，看到每一格。
- 「座號 N 不在名冊裡」：先請老師把孩子加進 `roster.csv`。
- 「資料庫裡還有名冊沒有的座號部落格」：只是提醒（轉出的孩子），不會刪；要刪走資料退場。
- 放了頭像卻說需要 Pillow：把官方連結與那一行指令給老師自己貼。
