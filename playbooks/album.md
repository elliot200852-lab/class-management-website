# 劇本：上傳相簿

老師會說：「上傳相簿」「把運動會的照片放上去」「相簿加幾張」「相簿放影片連結」。

腳本：`scripts/publish_album.py`。相簿資訊在 `data/albums/<slug>.md`，照片放同名資料夾 `data/albums/<slug>/`（全部都會上傳，依檔名排序）。
寫法說明：`data/albums/README.md`。**兩段式**：預設只預覽，老師說好才 `--publish`。

## 1. 代理要問什麼（一次一題）

1. 「這本相簿叫什麼名字？是哪一天的活動？」
2. 「照片放在哪裡？」——請他把**已經挑好**的照片放進 `data/albums/<slug>/`（你告訴他資料夾位置）。不要替他挑照片。
3. 「有影片嗎？」影片不上傳，只放連結：請他把影片傳到 YouTube（設「不公開」）或雲端硬碟（分享範圍他自己決定），給你連結與標題。
4. 「有哪幾張要寫圖說？」沒說就都不寫，**不要替他編**。

## 2. 老師去哪裡拿

- 照片：從手機或相機傳到電腦，放進那個資料夾。檔名會決定順序（`01.jpg`、`02.jpg`…），原始檔名不會上網。
- 影片連結：YouTube → 上傳 → 瀏覽權限選「不公開」→ 複製連結；或 Google 雲端硬碟 → 右鍵 → 共用 → 複製連結。

## 3. 代理要做什麼

1. 檔名（slug）：`日期-英文小寫`，例如 `2026-10-02-sports-day`；建 `data/albums/<slug>.md`（檔頭 `title`、`date`，
   影片寫在 `videos:` 底下「- 標題 | 網址」，圖說寫在 `captions:` 底下「- 檔名 | 圖說」；檔頭下面的文字是相簿說明）。
2. 預覽（唯讀，直接跑；照片多的話處理要一兩分鐘）：
   ```
   python3 scripts/publish_album.py <slug> --open
   ```
   跟老師確認：幾張、封面是哪張、影片連結對不對。
3. 他說好：「我接下來要把這本相簿放上網站，名單上的家長登入後就看得到」，他點頭才跑：
   ```
   python3 scripts/publish_album.py <slug> --publish
   ```
4. 之後要加照片、拿掉照片、改說明、換封面、下架（`visible: false`）：改資料夾或 md，預覽，他同意後 `--publish --update`。
   已經上傳過的照片不會重傳；拿掉的照片會從網站上刪掉。

## 4. 怎麼驗證＋失敗怎麼辦

- 成功：「✓ 已上線……讀回比對一致」。網站的相簿頁重新整理就看得到，不用重新部署。
- 請老師用手機點開幾張看（方向、清楚程度）。網站上的是壓縮過的版本；原圖請他自己留著（這台電腦或雲端硬碟）。
- exit 2：「一本最多 300 張」→ 拆成兩本；「captions 寫了某張但資料夾裡沒有」→ 檔名打錯；「網址不是 https://」→ 重新複製連結；
  「已經上線」→ 照第 4 步問他要不要 `--update`；「需要 Pillow」→ 把官方連結與那一行指令給他自己貼。
- exit 1：照訊息的「→」處理。大相簿是分好幾批送的，中途斷掉就修好後重跑同一個指令（已經送上去的照片不會重傳）。
- 「今天的免費額度用完了」：Spark 每天寫入 20,000 次（一張照片算 2 次），台灣時間下午 4 點左右恢復，隔天再跑同一個指令。
