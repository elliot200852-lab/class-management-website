# 劇本：發班級紀事

老師會說：「發班級紀事」「把今天的事寫成紀事」「上傳這篇」「改一下那篇」「那篇先下架」。

腳本：`scripts/publish_post.py`。母本在 `data/class-posts/<slug>.md`，照片在同名資料夾 `data/class-posts/<slug>/`。
寫法說明：`data/class-posts/README.md`。**兩段式**：預設只產生預覽，老師說「上傳」才加 `--publish`。

## 1. 代理要問什麼（一次一題）

1. 「這篇要寫什麼？」（他口述、貼文字、或已經有寫好的稿）
2. 「標題要叫什麼？日期是哪一天？」（沒說就用今天，跟他確認）
3. 「放哪一個分類？」——只能選 `config/class.json` 的 `categories` 裡的其中一個，把選項念給他聽。
4. 「有照片嗎？請把照片放進 `data/class-posts/<slug>/`（我會告訴你資料夾在哪）。」照片的圖說他沒給就留空，**不要替他編**。

## 2. 老師去哪裡拿

- 照片：手機拍的直接傳到電腦（AirDrop、LINE 傳給自己、雲端硬碟）存進那個資料夾就好。iPhone 的 HEIC 格式讀不了的話，
  腳本會說兩個辦法（裝 HEIC 支援、或手機相機改「最相容」）。
- 分類：`config/class.json` 的 `categories`。想加新分類要改那個檔再部署（`deploy.md`），不是這支腳本的事。

## 3. 代理要做什麼

1. 決定檔名（slug）：`日期-英文小寫`，例如 `2026-10-01-autumn-walk`。只能英文小寫、數字、連字號。
2. 寫 `data/class-posts/<slug>.md`（檔頭：`title`、`date`、`category`，選填 `cover`、`excerpt`、`visible`）。
   正文只用 README 表格裡的寫法；照片寫成單獨一行 `![圖說](檔名)`。
   **老師的原話照原樣放**，不要潤飾他沒要求潤飾的字。
3. 產生預覽（唯讀，直接跑）並打開給他看：
   ```
   python3 scripts/publish_post.py <slug> --open
   ```
   把輸出的摘要念給他：標題、日期、分類、誰看得到、幾張照片、列表摘要。
4. 他改稿：請他直接改 md 檔（或告訴你改哪裡、你改），**改完重跑預覽**。上傳一律以磁碟上的檔為準。
5. 他說「上傳」：先說一句「我接下來要把這篇放上網站，名單上的家長登入後就看得到」，他點頭才跑：
   ```
   python3 scripts/publish_post.py <slug> --publish
   ```
6. 已經上線的要改（改字、換照片、下架）：改好 md（下架＝檔頭寫 `visible: false`），預覽給他看，他同意後：
   ```
   python3 scripts/publish_post.py <slug> --publish --update
   ```
   不加 `--update` 腳本會擋下來（避免不小心覆蓋已上線的內容）。**`--update` 一定要老師明確同意才加。**

## 4. 怎麼驗證＋失敗怎麼辦

- 成功：最後一行「✓ 已上線……讀回比對一致」。網站不用重新部署，重新整理就看得到：`<網站>/post.html?s=<slug>`。
  `data/class-posts/index.md` 會自動記下這篇。
- 請老師用手機打開網站看一次（照片方向、字有沒有錯）。
- exit 2：
  - 「沒有覆蓋已上線的內容」＝這篇已經上線，要改就照第 6 步問他。
  - 「category 不在分類裡」「找不到照片」「正文是空的」「檔頭有不認得的欄位」：照訊息修 md 再預覽。
  - 「處理照片需要 Pillow」：把腳本印的官方連結與那一行指令給老師，請他自己貼（不要替他裝），裝好再跑。
- exit 1（gcloud、權限、網路）：照訊息的「→」處理，修好再跑同一個指令；已經寫進去的照片不會重複寫。
