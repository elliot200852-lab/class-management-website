# class-management-website

一個給老師用的班級網站，加上一個放在你自己電腦上的班級資料夾。家長用自己的帳號登入以後，才看得到班上的紀事、相簿和自家孩子的部落格；
沒登入的人只會看到一個登入畫面。網站架在**你自己的** Google（Firebase）帳號底下，名單與原始檔留在你的電腦和你自己的雲端硬碟裡。

安裝和日常操作都交給你的 AI 代理（Claude Code、Codex、Antigravity 等能讀檔案、能跑指令的助手）：
你只要回答它的問題、照它說的去官方網站裝幾個程式、在 Google 的網頁上點幾個設定。

MIT 授權、免費、**依現狀提供，不提供維護與支援服務**。

## 它能做什麼

| 誰 | 看得到、做得到的事 |
|---|---|
| 沒登入的人 | 只有登入畫面。整個網站也設定成不被搜尋引擎收錄 |
| 班上家長與你邀請的同事（名單上的人） | 首頁、班級紀事（含分類）、相簿與影片連結、課程頁、專題活動、關於我們、班級行事曆訂閱；在紀事與相簿底下留言 |
| 對到座號的家長（用 Google 帳號登入） | 「我的孩子」：自己孩子的部落格，看導師寫的文章、自己也能發文（最多 3 張照片），和導師在文章底下對話。看不到別人的孩子 |
| 你指定可以看某個座號的同事 | 讀那個座號的部落格文章（看不到家長與導師的對話） |
| 私密名單上的人 | 另外看得到私密紀事（只給少數人看的內容） |
| 導師（你） | 以上全部，加上：留言後台（顯示／隱藏留言）、「我的孩子」全班總覽與新留言提示、每篇紀事的已讀人數、導師專用頁 |

你這邊（透過 AI 代理，一句話一件事）：發班級紀事、上傳相簿、替某個座號發部落格、發私密紀事、改首頁與單頁、更新課程頁與課表、
科任大綱入檔、同步家長名單（新增、換信箱、轉出）、備份到你的 Google 雲端硬碟、整理班級文件索引、健檢。
每一件都先給你看預覽，你說好才上線。要寫信給某位家長時，代理幫你把觀察寫成草稿，用你電腦的郵件程式打開，**由你自己按傳送**。

## 它不做什麼

- 不公開任何東西：沒有不用登入就能看的頁面、照片或網址。
- 不存影片檔：影片請放 YouTube（不公開）或雲端硬碟，網站只放連結。
- 預設不寄通知信。「有新留言就寄信給你」「你發文後寄信給家長」「每日摘要」是**選配模組**，要你想要才裝（見下面「選配：通知信」）。
- 不做學生觀察與成績紀錄。
- 不替你安裝任何工具、不代管任何帳號或資料。作者看不到你的網站、名單或資料。
- 不提供客服。遇到問題由你的 AI 代理照說明書查；查不出來就只能自己想辦法或暫停使用。

## 選配：通知信

- **誰需要**：想要有人留言、家長發文就馬上收到信，或希望自己在孩子的部落格發文後，家長收到一封提醒信（30 分鐘後才寄，
  這段時間內下架就不寄），以及每天早上一封摘要的老師。不裝，網站照常運作。
- **要付出什麼**：專案要升級成 Firebase 的 **Blaze（隨用隨付）方案**、綁信用卡，並設預算警示（警示只寄信提醒、不會自動停止收費）。
  一個班的用量通常落在免費額度內，以官方價目頁為準（<https://firebase.google.com/pricing>）。另外要一個寄信用的 Gmail 帳號
  ＋應用程式密碼（學校帳號常被管理員關掉，就另開一個個人 Gmail）；密碼由你自己貼進 Google 的 Secret Manager，AI 代理不經手。
- **信裡有什麼**：只有座號、標題、連結；不夾留言與文章內容。家長的信一位一封，只寄給用 Google 帳號對到座號的家長。
- **怎麼開、怎麼關**：跟代理說「通知信」，它照 `playbooks/notify.md` 帶你裝；先用「預演」（給家長的信只記錄、不寄）試一兩天再正式開。
  隨時可以說「通知信先停」（一行指令、立刻生效），也可以整組移除、回到免費方案。

## 隱私是怎麼設計的

- **由伺服器把關。** 誰能看什麼寫在 Google 伺服器端的規定裡，網頁本身只是空殼；不在名單上的帳號，就算知道網址也拿不到內容。
- **照片清掉定位資訊。** 上傳的照片（包括家長在網頁上傳的）會重新壓縮，拍攝地點、相機資料等 EXIF 一律清掉；原始檔不上網站。
- **留言不公開家長信箱。** 留言與部落格只存一組隨機代號，只有導師端對得回是哪一位家長。
- **名單只在你那裡。** 學生姓名、家長信箱只存在你電腦的 `data/` 資料夾（不會被版本控制帶走），以及你自己的 Firebase 專案與雲端硬碟裡。
- **AI 代理看不到名冊。** 說明書規定代理不打開名冊與聯絡人檔，只看程式遮過的結果（座號、稱謂、`p***@gmail.com` 這樣的信箱）。
- **這個公開的程式庫裡沒有任何一筆真實資料**；示範用的學生、家長、照片全是虛構或程式畫的。

## 你需要準備什麼

- 一台 **Mac**（macOS 13 以上較保險）或 **Windows 10／11** 電腦。
- 一個 **Google 帳號**：自己的 Gmail，或學校的 Google 帳號（有些學校不讓老師自己開專案，AI 代理會帶你試一次就知道）。
- 一個 **AI 代理**。多半需要付費訂閱，各家方案以官方網站為準。
- 一支手機（最後試跑用）。大約兩到四小時，可以分好幾天做。
- 費用：網站用 Google Firebase 的**免費方案（Spark）**，不用綁信用卡；一個班一學年通常用得完。照片非常多、或想取消每天 5 封登入信的限制，
  可以之後再升級成隨用隨付的方案（不用改任何程式）。

## 三步開始

### ① 從官方網站裝一個 AI 代理（選一個）

| 代理 | 官方安裝說明 | 啟動指令 |
|---|---|---|
| Claude Code（Anthropic） | <https://code.claude.com/docs/en/setup>；第一次用終端機的人看 <https://code.claude.com/docs/en/terminal-guide> | `claude` |
| Codex CLI（OpenAI） | <https://learn.chatgpt.com/docs/codex/cli>（原始碼 <https://github.com/openai/codex>） | `codex` |
| Antigravity CLI（Google） | <https://github.com/google-antigravity/antigravity-cli> | `agy` |
| Gemini CLI（Google） | <https://github.com/google-gemini/gemini-cli> | `gemini` |

Google 已在 2026 年 6 月把一般帳號（免費、Google AI Pro／Ultra）的 Gemini CLI 換成 Antigravity CLI；
Gemini CLI 目前只給企業授權或付費 API 金鑰的使用者（官方公告：
<https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli>）。用個人 Google 帳號的請選 Antigravity CLI。

照官方說明裝好、登入你自己的帳號。

### ② 下載這個資料夾

- **最簡單**：在這個頁面（<https://github.com/elliot200852-lab/class-management-website>）按綠色的 **Code** →「**Download ZIP**」，
  解壓縮，把資料夾放在你的個人資料夾裡（Mac：Finder「前往 → 個人專屬」；Windows：`C:\Users\你的名字\`）。
  **不要放在 iCloud、OneDrive 或 Google 雲端硬碟會自動同步的地方**（例如有開同步的「桌面」「文件」）：之後學生名單會放在這個資料夾裡。
- 會用 git 的：`git clone https://github.com/elliot200852-lab/class-management-website.git`

### ③ 在資料夾裡打開代理，貼上一句話

打開終端機並進到這個資料夾：

- Mac：打開「終端機」（⌘＋空白鍵，搜尋「終端機」），打 `cd`、空一格，把資料夾從 Finder 拖進視窗，按 Enter。
- Windows：用檔案總管打開這個資料夾，在上方網址列輸入 `cmd`，按 Enter。

然後打代理的啟動指令（上表最右欄），貼上這一句：

```
請完整讀 AGENTS.md，帶我一步一步把班級網站裝起來。
```

用代理的桌面版的話，在程式裡選擇這個資料夾，再貼同一句話。

想先看看網站長什麼樣再決定：改貼「請完整讀 AGENTS.md，先帶我試玩」——代理會照 `playbooks/try.md` 在你的電腦上開一個虛構班級的網站
（不用任何帳號、不碰雲端；要 Node.js 與 Java）。

之後就是代理一題一題問你。它每次要執行指令時會問你可不可以，這是正常的；看不懂可以直接問它那一行在做什麼。
做到一半要休息也沒關係，下次一樣在這個資料夾打開代理，說「繼續安裝」。

## 驗證到哪裡（照實說）

**有驗過的**（全部在模擬環境或自動測試裡，沒有碰任何真的雲端專案）：

- 伺服器端權限規則：4,000 多個模擬器測試案例，逐格檢查每一種身分（未登入、名單外、家長、同事、私密讀者、導師等）
  對每一類資料的讀寫，允許與拒絕兩面都測。
- 用真的 Firebase 網頁程式庫接模擬器的冒煙測試：登入、看紀事、留言、已讀、家長發文、照片清掉定位資訊、看不到別人的孩子。
- 管理程式（名單同步、發文、相簿、部落格）寫進模擬器後，再用真規則讀回比對。
- 選配的通知信模組：Firestore＋Functions 模擬器裡跑觸發器、30 分鐘延遲與取消、預演不寄給家長、不重寄的逐人台帳、每日摘要
  （模擬器裡的郵差是假的，從來沒有寄出任何一封真的信）。
- 自動測試在 Ubuntu、macOS、Windows 三個平台跑（權限規則、冒煙測試與通知信模組只在 Ubuntu 跑）。

**作者從來沒有在真的 Firebase 專案上跑過這套。** 下面這些只有在你自己的專案、你自己的手機上才驗得到，安裝第 8 步會請你親手確認：

- Firebase 主控台的建立步驟與按鈕名稱（Google 常改版）
- 真的 Google 登入畫面、手機瀏覽器擋彈出視窗時的替代流程
- 信箱登入連結的寄送（免費方案每天 5 封）
- 從 LINE 點網址時改用手機瀏覽器開的流程
- iPhone 照片（HEIC、拍攝方向）在真手機上發文
- 真的部署：網站位置、資料庫索引建立的時間、雲端健檢程式呼叫的各個 Google 服務
- 免費額度用完時的實際畫面
- 學校管理的 Google 帳號會不會擋掉登入工具
- Windows 真機從零安裝（自動測試只涵蓋程式本身）、Google 雲端硬碟電腦版的實際同步
- 版本之間的升級
- 通知信模組的一切真實行為：Gmail 寄信與應用程式密碼、第一次部署 Functions、排程的實際時間、信會不會進垃圾郵件、Blaze 的帳單
