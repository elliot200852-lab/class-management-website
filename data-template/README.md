# data-template/ — 空白資料框架

這個資料夾是「這個班的資料應該長什麼樣子」的空白骨架，**有進 git**（跟著程式碼一起公開）。
它本身不含任何一筆真實資料。

安裝時跑 `python3 scripts/init_data.py`，會把這整棵樹複製成 `data/`（已經存在的檔不覆蓋）。
`data/` 才是這個班**真正的資料**，一律不進 git（見 repo 根的 `.gitignore`）。

每個子目錄底下都有一份自己的 `README.md`，說明那個目錄放什麼、誰會寫進去、
會不會被同步到雲端。下面是總覽：

| 目錄 | 放什麼 | 含真名？ | 會上雲嗎 |
|---|---|---|---|
| `roster.csv` | 學生名冊：`座號,姓名,稱呼,備註`（「稱呼」＝家長在網站上看到的孩子稱呼，只放名） | 會 | 全名與稱呼寫進只有導師讀得到的 `roster/students`；稱呼另外放在該座號的部落格主頁 |
| `contacts.csv` | 誰能進網站：`座號,關係,姓名,Email,私密讀者,暫停,備註`（一列一個「人×座號」；同仁的「關係」填「同仁」） | 會 | 姓名不上雲；email 換算成名單（只有本人與導師讀得到自己那份） |
| `parent-roles.yaml` | 每個座號「應該有帳號」的家長稱謂（不放 email、不放姓名），名單同步的安全閘正本 | 不含 | 不會 |
| `class-posts/` | 班級紀事歷程母本 | 視內容而定 | 正文會同步到網站資料庫（登入才讀得到） |
| `student-blogs/` | 學生部落格的本機鏡像（`backup.py blogs` 匯出） | 視內容而定 | 正本在雲端資料庫；匯出時同時複製到雲端硬碟 `04_部落格歸檔/` |
| `units/` | 課程單元資料（大綱、教案、文本；`new_block.py` 從範本開） | 通常不含學生個資 | 不上網站；`backup.py records` 備份到雲端硬碟 |
| `courses/` | 課程紀錄 `<單元>/records.md`（子資料夾）；課程頁與課表 `courses-*.md`、`schedule.md`（這一層的 md）；科任大綱的文字檔 `syllabi/` | 課程紀錄只寫座號；課程頁不含 | 課程紀錄與 `syllabi/` 不上網站；這一層的 md 由 `publish_courses.py --publish` 上網站；全部由 `backup.py records` 備份到雲端硬碟 |
| `albums/` | 相簿：`<slug>.md`（標題、說明、影片連結）＋同名資料夾的照片 | 視照片而定 | 照片壓縮、清掉 EXIF 後進網站資料庫（登入才讀得到）；原圖不上雲 |
| `private-posts/` | 私密紀事母本（只有私密讀者看得到） | 視內容而定 | 發布後進網站資料庫 |
| `pages/` | 單頁：關於我們、專題活動、首頁橫幅、獨立單頁 | 通常不含 | 發布後進網站資料庫 |
| `blog-drafts/` | 導師替某位孩子發的部落格文章草稿（`<座號>/<草稿名>.md`） | 視內容而定 | 發布後進網站資料庫 |
| `avatars/` | 部落格主頁的頭像（選用，檔名只准座號） | 照片 | 縮成小圖後進網站資料庫 |
| `seating/` | 座位表：一個方案一個 JSON（`<起用日期>.json`），**只寫座號** | 不含（名字由網站用名冊的稱呼補上） | `publish_seating.py --publish` 才上雲；只有導師讀得到 |
| `personal-photos/` | 導師限定的個人照：一位學生一張，**檔名只用座號**（`01.jpg`） | 孩子的照片 | `publish_personal_photos.py --publish` 才上雲（清 EXIF、壓縮）；只有導師讀得到 |
| `parent-photos/` | 家長合照（選用；建議檔名只用座號） | 家長與孩子的照片 | `publish_parent_photo.py --publish` 才上雲；雲端只存稱謂、不存家長姓名；只有導師讀得到 |
| `poems/` | 每日一詩：一首一個 md（檔頭要有老師確認過的 `rights`） | 不含 | `publish_poems.py --publish` 才上雲（一個月一份）；名單上的讀者看得到；`rights` 只留在本機 |
| `backups/` | 網站資料庫的本機快照與照片池（`backup.py`） | 含 | 會：每次備份都複製到雲端硬碟 `05_全站備份/` |
| `ledgers/` | 各種台帳（備份狀態、歸檔紀錄、md5……） | 視內容而定 | 包進紀錄備份 |
| `inbox/` | 上課的照片、影片、錄音、講義，等著課程歸檔（`archive_media.py`） | 視內容而定 | 歸檔後的那一份在雲端硬碟（只有導師看得到）；處理完應該清空 |
| `exports/` | 匯出的 Word／PDF／HTML、預覽檔（AI 代理禁讀） | 視內容而定 | 不會 |
| `parent-notes/` | 家長通知信草稿（孩子寫成〔孩子〕；寄出時才由腳本換成真實稱呼） | 不含真名 | 不會 |
| `records/` | 指向 teacher-records-kit 資料（學生觀察、課程紀錄） | 含 | 由 teacher-records-kit 自己的規則管，不是這個框架管 |

**座號一律用兩位數字字串**（`01`–`40`），程式、檔名、路徑全部統一——見 `scripts/lib/seats.py`。
