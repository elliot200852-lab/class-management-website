# data/poems/

「每日一詩」：一首一個 `.md` 檔，放上網站後**名單上的家長與同仁**登入就看得到（一天揭曉一首）。

- **版權由老師負責。只放老師確認過可以公開使用的文本**：公版作品（作者過世夠久、確定已進入公共領域）、
  老師或孩子自己寫的、或已經取得授權的。有著作權的現代作品，就算只是班級網站、只給家長看，也不要整首放上來。
- 每一首的檔頭都要有 `rights`：寫這首**為什麼可以公開使用**（例如「公版」「老師自己寫的」「已取得作者同意」）。
  `rights` 空白的詩，預覽看得到，但 `scripts/publish_poems.py … --publish` 會擋下來。**這一欄只有老師能決定**，
  AI 助理不會替你填，也不會憑記憶打出現代作品的全文（劇本 `playbooks/poem.md`）。
- `rights` 只留在這台電腦（上網的只有日期、詩名、作者、出處、正文、導讀）。
- **不含學生個資**；孩子自己寫的詩，作者欄寫「本班學生」之類，不要寫全名。

## 格式（範例：`2026-10-01.md`，檔名建議就用日期）

```
---
date: 2026-10-01
title: 詩名
author: 作者
source: 出處（書名、頁數或網址；可省略）
rights: 公版
---
詩的正文，每一行照原樣。
  行首的空白、段落之間的空行都會保留。

## 導讀
（可省略）一小段導讀：這首詩可以怎麼跟孩子聊。
```

- 一個月一份：`python3 scripts/publish_poems.py 2026-10` 預覽十月，老師說好再加 `--publish`（網站上已經有十月、又改過的加 `--update`）。
- 同一天只能有一首；日期要落在那個月裡。詩的正文最多 2,000 字、導讀最多 1,000 字。
- 網站上：預設看今天那一首，下面列出這個月的每一首；還沒到的日子只有導師看得到。
