# data/personal-photos/

導師限定的**個人照相簿**：一位學生一張照片，放上網站後**只有導師**看得到（家長與同仁都讀不到）。

- **檔名只用座號**：`01.jpg`、`02.png`、`7.jpg` 都可以；**不要用孩子的名字當檔名**。
  檔名不是座號的照片，`scripts/publish_personal_photos.py` 會擋下來（而且不會把檔名印出來）。
- **一號一張**：同一個座號放兩張會被擋下來。要換照片＝直接換掉這裡的檔，再跑一次（加 `--update`）。
- **上網前會先處理**：依拍攝方向轉正、清掉 EXIF 與定位資訊、壓成顯示圖與縮圖兩份。原圖與原始檔名都不會上網。
- **AI 助理不打開這裡的照片**（孩子的臉）：它只跑腳本、看腳本印的座號與張數；照片對不對由老師看預覽檔確認。
- 劇本：`playbooks/personal-photos.md`。學生轉出時，記得把他的照片從這裡移到垃圾桶（`data_exit.py seat` 會一起處理）。
