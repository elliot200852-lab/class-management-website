# data/albums/

相簿：每一本一個 `<slug>.md`（相簿資訊）＋同名資料夾 `<slug>/`（這本的全部照片）。
由 `scripts/publish_album.py` 送上網站。

- **照片**：資料夾裡的照片**全部**上傳，依檔名排順序（`01.jpg`、`02.jpg`…）。上傳前自動轉正、清掉 EXIF 與 GPS、
  壓成縮圖與顯示圖兩份，存進網站資料庫（登入才看得到）；原圖不上雲、原始檔名也不上雲。原圖請自己留在這台電腦或雲端硬碟。
- **影片**：不上傳影片檔，只放連結（YouTube「不公開」或雲端硬碟分享連結，分享範圍由老師自己決定）。
- 一本最多 300 張；更多就拆成兩本。

## 檔名（slug）

`日期-英文小寫與數字`，例如 `2026-10-02-sports-day.md` ＋ `2026-10-02-sports-day/`。

## 檔頭

```
---
title: 運動會                 必填，1–80 字
date: 2026-10-02              必填
order: 0                      選填：排序用的整數，小的排前面
cover: 03.jpg                 選填：封面（不寫就用第一張）
link: https://…               選填：整本相簿另外的外部連結
videos:                       選填：最多 20 支
  - 大隊接力 | https://www.youtube.com/watch?v=…
captions:                     選填：照片圖說（沒寫的就沒有圖說，不要替老師編）
  - 03.jpg | 起跑的那一刻
visible: true                 選填：false＝下架
---
檔頭下面的文字＝相簿說明（純文字，最多 1000 字）。
```

## 發布

`python3 scripts/publish_album.py <slug>`（預覽）→ 老師說好 → `--publish`；之後加照片、改說明、下架：`--publish --update`。
