# data/class-posts/

班級紀事的**母本**：每一篇紀事先在這裡寫成 `<slug>.md`（草稿、修訂），照片放在同名資料夾
`<slug>/`。確定要發布了，再由 `scripts/publish_post.py` 送上網站。`index.md` 由發布腳本自動產生
（發過哪幾篇、網址、最後上線時間），不要手改。

- **誰寫**：老師（或老師的 AI 代理照老師口述整理，**寫完一定先給老師看、老師改過的以磁碟上的檔為準**）。
- **會不會上雲**：這裡的檔案本身不上雲；發布之後，正文與照片的**副本**進網站資料庫（登入且有權限的人才讀得到）。
- **照片**：只有正文裡用到的（和檔頭 `cover` 指定的）才會上傳；上傳前自動轉正、清掉 EXIF 與 GPS、縮成網站用的大小。
  照片的原始檔名不會上雲。

## 檔名（slug）

`日期-英文小寫與數字`，例如 `2026-10-01-autumn-walk.md`（照片放 `2026-10-01-autumn-walk/`）。
只能用英文小寫、數字、連字號，最長 80 字。這也是網址的一部分：`<網站>/post.html?s=2026-10-01-autumn-walk`。

## 檔頭（最上面用 `---` 包起來）

```
---
title: 秋天的散步          必填，1–120 字
date: 2026-10-01          必填，YYYY-MM-DD
category: 班級生活         必填，要是 config/class.json 的 categories 之一
cover: leaves.jpg         選填：列表上的封面（不寫就用正文第一張照片）
excerpt: 一句話摘要        選填：列表卡片上的摘要（≤ 200 字；不寫就取正文開頭）
visible: true             選填：false＝下架（家長看不到，只有導師看得到）
---
```

## 正文寫法（只有這幾種，其他寫法原樣當文字）

| 寫法 | 效果 |
|---|---|
| 空一行 | 分段（段落內的換行照原樣保留） |
| `## 小標題`、`### 更小的標題` | 標題 |
| `- 項目`、`1. 項目` | 清單 |
| `> 一句話` | 引言 |
| `---`（單獨一行） | 分隔線 |
| `![圖說](leaves.jpg)`（單獨一行） | 照片（檔名寫同名資料夾裡的照片；圖說可以空著，**不要替老師編**） |
| `[[video:https://www.youtube.com/watch?v=…]]` 或 `[[video:網址\|影片標題]]`（單獨一行） | 影片連結（影片不上傳，只放連結） |
| `**粗體**`、`*斜體*`、`[文字](https://…)` | 粗體、斜體、連結（只有 https:// 的連結會變成連結） |

## 發布（兩段式）

1. `python3 scripts/publish_post.py <slug>`：只產生預覽 `exports/preview/post-<slug>.html`，給老師看。
2. 老師說「上傳」：`python3 scripts/publish_post.py <slug> --publish`。
3. 已經上線的要改（改字、換照片、下架）：改好 md 後 `--publish --update`。

（Windows：`py -3 scripts/publish_post.py …`）
