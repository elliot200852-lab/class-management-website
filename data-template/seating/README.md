# data/seating/

座位表：一個方案一個 JSON 檔，放上網站後只有**導師**看得到（導師專用頁的「座位表」分頁）。

- **誰寫**：AI 助理照老師說的座位寫成檔案（劇本 `playbooks/seating.md`），或老師自己照下面的格式寫。
- **只寫座號、不寫名字**：網站上的名字是用名冊裡的「稱呼」當場補上的；雲端的座位表只存座號。
  格子裡寫了名字，`scripts/publish_seating.py` 會擋下來（而且不會把那個字印在畫面上）。
- **座號寫法**：兩位數字的文字，`"01"`–`"40"`（前後要有引號）；名冊（`roster.csv`）裡沒有的座號會被擋下來。
- **會不會上雲**：跑 `publish_seating.py … --publish` 才會；家長與同仁都讀不到。

## 檔名＝方案代號

`YYYY-MM-DD.json`，日期是「這一天起用」。同一天排了好幾種，第二個寫 `YYYY-MM-DD-2.json`、第三個 `-3`……
網站預設顯示「起用日期在今天以前、最新的那一個」，其他方案可以切換著看。

## 格式（範例：`2026-10-01.json`）

```json
{
  "title": "十月的座位",
  "date": "2026-10-01",
  "note": "一段只有導師看得到的備註（可省略）",
  "rows": [
    ["01", "02", "-", "03", "04"],
    ["05", "06", "-", "07", "08"],
    ["09", "",   "-", "10", "11"]
  ]
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `title` | ✓ | 方案名稱，1–60 字 |
| `date` |  | 起用日期；省略＝檔名的日期 |
| `note` |  | 備註，最多 500 字 |
| `rows` | ✓ | 一排一個清單，**第一排＝最靠黑板**；每一排由左到右是「學生面向黑板時」的左右。最多 15 排、每排 15 格 |

格子只有三種寫法：座號（`"01"`）、空位 `""`（畫一張空桌子）、走道 `"-"`（不畫桌子，用來分組）。
每一排會置中對齊，所以前後排人數不一樣也會自然錯開。
網站上可以切換「老師站在講台看（黑板在下）」和「學生面向黑板看（黑板在上）」兩種方向，也可以直接列印（A4 橫式）。
