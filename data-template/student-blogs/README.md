# data/student-blogs/

學生部落格（「我的孩子」功能）內容的**本機備份**，一個座號一個子資料夾：`data/student-blogs/<座號>/`。

- **誰寫**：正本是家長與老師在網站上發的文章；這裡的檔由 `python3 scripts/backup.py blogs`（或 `all`）匯出，**不要手改**：
  每篇一個 `<文章代號>.md`（標題、日期、作者是家長或導師、網站上顯示中或已下架、正文逐字保留、導師與家長的對話串），
  照片存成 `<文章代號>-<0|1|2>.jpg`。
- **會不會上雲**：匯出時同時複製到雲端硬碟 `04_部落格歸檔/<座號>/<學年>/`（資料夾只用座號，不用姓名；逐檔比對 md5）。
- 網站上刪掉的文章，這裡的舊檔不會自動刪（備份的意思）；學生轉出、家長要求刪除時走 `playbooks/data-exit.md`，會一起清。
- **座號寫法**：兩位數字字串，`01`–`40`（見 `scripts/lib/seats.py`）。
