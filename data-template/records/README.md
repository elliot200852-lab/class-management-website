# data/records/

學生觀察、課程紀錄——**這個框架本身不做這件事**。需要的話，可以另外用一套專門的紀錄工具，
例如開源的 [teacher-records-kit](https://github.com/elliot200852-lab/teacher-records-kit)（選用、另一個獨立專案）。
這裡只是預留一個指向點，用法：

1. 在同一台電腦另外安裝那套紀錄工具（用它自己的一個獨立 Firebase 專案）。
2. 這個目錄可以放一個捷徑／symlink，或就只是留著這份說明，指向那套工具自己的 `data/` 資料夾。
3. 導師專用頁的「學生觀察與課程紀錄」按鈕：`scripts/publish_site.py --records-kit "<網址>"`（AGENTS.md「導師專用頁的兩個入口」）。

不要在這裡直接複製紀錄工具的程式碼或資料格式——那會讓兩邊分岔，
之後那套工具修的安全性問題，這裡也要重修一次。統一用「另外安裝一套」的做法。
